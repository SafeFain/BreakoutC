# 任务归档:web 版玩法与特效扩展

- **日期**:2026-08-06
- **状态**:已完成(归档)
- **关联版本**:`web/`(TypeScript + Vite)

## 目标

为 web 版增加新玩法功能与画面特效(用户需求:经典扩展 + 华丽霓虹风)。

## 实施内容

### 新砖块
- **彩虹砖 `R`**:3 血,按 hp 渐变色(青→紫→粉),击碎三色粒子爆发
- **再生砖 `G`**:打碎后 5 秒原位重生,倒计时渲染虚线幽灵框(末 1 秒闪烁),重生带音效 + 圆环
- 4 个现有关卡混入新砖,新增第 5 关「彩虹矩阵」

### 新道具
- **激光**:拾取后挡板每 2.2s 自动发射双光束,可摧毁砖块、打不动不可摧毁砖
- **粘球**:球吸附挡板(虚线提示),空格再发射
- **巨球**:球半径 ×1.5,判定同步放大(修复 `intersects` 使用固定 `BALL_RADIUS` 的问题)

### 特效系统
- 新建 `src/fx.ts`(`FxSystem`):粒子(自 game.ts 迁移)/ 旋转碎片 / 得分飘字 / 扩散圆环 / 全屏闪光 / 屏幕震动
- 触发点:打砖飘字、爆炸屏震 + 粉闪、combo 每 5 连金色爆发、拾取光环、失球红闪冲击
- 动态霓虹背景光点、打击缩放脉冲、连击边缘辉光(10/20 级变色)
- 尊重 `prefers-reduced-motion`

### 音效
- 新增彩虹变色 / 重生 / 连击 3 种合成音效(共 12 种)

## 验证

- `cd web && npm run build`(tsc strict)通过
- `vite preview` + curl:HTTP 200、产物正常
- 遗留:浏览器内人工试玩清单(键盘/鼠标/触屏、各砖种与道具生命周期、reduced-motion 降级)
